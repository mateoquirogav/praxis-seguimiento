# Elike · Sistema de herramientas

Vista previa de las tres páginas interactivas que PRAXIS desarrolla para la
tienda de Elike (Tiendanube). Funcionan con el catálogo, los precios y las
zonas de cobertura reales de elike.com.ar.

- `compatibilidad.html` — recomendador de producto en 4 pasos
- `comparativa.html` — comparador técnico de hasta 3 modelos
- `cotizar-instalacion.html` — cotizador de instalación en 4 pasos

Toda la base de datos (modelos, especificaciones, zonas y precios de
instalación) vive en `assets/modelos.js`. Se edita ahí y las tres
herramientas se actualizan solas.

Diseño y desarrollo: PRAXIS.
